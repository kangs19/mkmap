# ADR-010. 가격 소스 분리 — KAMIS(차트·예측·모델) vs 실시간 경락가(지역)

- Status: Accepted
- Date: 2026-07-04

## Context
KAMIS 도매가(품목단위, 긴 히스토리)와 agromarket 실시간 경락가(원/kg, 지역별)가 단위·수준이 달라 혼용 시 오표시(예: 예측 162원 vs 차트 8,400원).

## Decision
차트·예측·모델 base는 KAMIS 전국가(품목단위)로 통일. 지역 실시간 경락가는 지도 색·'지역 도매가' 보조표시로 단위(원/kg) 명기. (PRD Ch.6: 산지가 혼동 금지)

## Consequences
장점: 일관성. 향후 두 소스를 하나의 정규화 계층으로 통합 검토.
