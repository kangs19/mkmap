# MK-MAP 2.0 기획 방향

> 작성일: 2026-07-03
> 이 문서는 MK-MAP의 장기 방향성을 정의하는 최상위 기획 문서입니다.
> 모든 신규 기능 개발·제안은 이 문서, 특히 **18. 반드시 지켜야 할 원칙**을 기준으로 판단합니다.

현재 MK-MAP은 공공데이터 기반 농산물 가격 위험 신호 엔진이다.

하지만 앞으로의 목표는 단순한 가격 예측 사이트가 아니라 **"대한민국 농업 정보 플랫폼"** 으로 발전시키는 것이다.

---

## 1. 서비스 철학

절대 AI만으로 승부하지 않는다.

공공데이터는 누구나 사용할 수 있다. 후발주자도 동일한 API를 사용해서 더 좋은 모델을 만들 수 있다.

따라서 MK-MAP의 경쟁력은 다음 순서로 이동해야 한다.

AI 모델 → 플랫폼 → 사용자 → 커뮤니티 → **데이터 자산**

## 2. 핵심 전략

- AI는 서비스의 **엔진**이다. 커뮤니티는 서비스의 **자산**이다.
- AI는 객관적인 데이터를 분석한다. 사용자는 현장의 분위기를 제공한다.
- AI와 사람의 정보를 **분리해서** 제공한다.
- 절대로 사용자 댓글이나 사진을 예측모델의 학습데이터로 바로 사용하지 않는다.

## 3. AI 전략

현재 AI는 가격·거래량·생산량·기상·이벤트 등 **공공데이터 기반으로만** 유지한다.

사용자 데이터는 AI를 변경하지 않는다. 대신 **"현장 신호"** 로 표시한다.

예시:

```
[AI 분석]
배추 가격 상승확률 71%
위험도 보통

[현장 제보]
최근 병해충 제보 증가
인증 농부 12명 · 사진 37장
```

AI 예측과 현장 제보가 다를 경우:
"최근 현장에서는 병해충 제보가 증가하고 있습니다." 같은 안내문을 보여준다.

## 4. 작물 확장 전략

모든 작물에 AI를 만들려고 하지 않는다. **AI는 데이터가 충분한 작물만** 제공한다.

| 등급 | 작물 | 제공 내용 |
|---|---|---|
| ★★★★★ | 배추, 양파, 마늘, 무, 대파 | AI 예측 제공 |
| ★★★☆☆ | 감자, 고추, 사과, 토마토, 딸기 등 | AI 예측 없음 — 가격·기상·생산량·뉴스·커뮤니티·현장사진 제공 |

데이터가 부족한 작물은 사용자에게 **"AI 예측 준비중"** 이라고 솔직하게 표시한다. 데이터가 충분히 쌓이면 AI를 추가한다.

## 5. AI보다 먼저 만들 것 (우선순위)

① 커뮤니티 → ② 사용자 → ③ 사진 → ④ 현장 제보 → ⑤ AI 확장

## 6. 커뮤니티 구조

호갱노노를 벤치마킹하되, 단위를 **아파트 → 재배지역 × 품목** 으로 변경한다.

- 단위: 충청북도 → 괴산군 → 배추 ⇒ 최종 커뮤니티 = **"괴산군 배추"**
- 예: 괴산군 배추, 무안군 양파, 서산시 마늘, 평창군 배추
- 초기에는 **시군구 × 품목** 까지만 운영한다. 읍면동은 사용자가 많아질 경우에만 분리한다.

## 7. 회원 유형

1. **일반회원** — 조회, 댓글, 사진, 관심지역
2. **인증 농부** — 추가 기능: 우리지역 평가, 병해충 제보, 생육상태 평가, 출하량 평가, 사진 제보. "인증 농부" 배지 표시. 인증방법: 휴대폰 / 농업경영체 / 관리자 승인
3. **유통인** — 시장 분위기 제보
4. **관리자** — 승인, 신고처리

## 8. 현장 제보 ("우리지역 평가하기")

인증 농부 입력 항목:

- **생육상태**: 좋음 / 보통 / 나쁨
- **병해충**: 없음 / 있음 / 심각
- **출하량**: 증가 / 평년 / 감소
- **기상피해**: 폭염, 가뭄, 태풍, 우박, 호우
- **가격 체감**: 오를 것 같다 / 비슷 / 내릴 것 같다
- **사진** 업로드
- **한줄평**

## 9. 댓글

자유게시판이 아니다. **지역 × 품목** 기반이다.

예: "괴산 배추" — 댓글, 사진, 추천, 대댓글, 신고, 좋아요

## 10. 사진

사진은 매우 중요하다. 사용자는 작물·병해·밭·기상피해 사진을 올릴 수 있다.

향후 Vision AI 도입 가능하지만 **초기에는 참고용으로만** 사용한다.

## 11. 사용자 신뢰도 (Trust Score)

기준: 활동기간, 추천수, 신고수, 사진첨부, 인증여부, 지역활동 등

배지: 신규 → 일반 → 인증농부 → 지역전문가 → 신뢰회원

## 12. 지도

지도는 **AI + 커뮤니티** 를 함께 보여준다.

필터: AI 위험도, 사용자 평가, 병해충, 사진, 출하량 감소, 인증농부만 보기 등

## 13. AI 브리핑

우측 패널 최상단에 표시.

예: "괴산군 배추는 향후 30일 상승 가능성이 있습니다. 폭염과 생산량 감소가 주요 원인입니다."

## 14. 예측 이력

모든 예측을 저장한다.

예: `2026-07-01 | 예측: 상승 | 실제: 상승 | 적중`

사용자는 AI가 얼마나 맞았는지 확인 가능하다.

## 15. 데이터 자산

후발주자는 공공데이터·AI·모델은 따라할 수 있다. 하지만 다음은 복제하기 어렵다.

- 인증 농부
- 지역 커뮤니티
- 현장 사진
- 댓글
- 사용자 신뢰도
- 예측 이력
- 활동 데이터

이것이 MK-MAP의 진짜 경쟁력이 된다.

## 16. 개발 우선순위

**1단계**: AI 브리핑, 커뮤니티 기본 구조, 댓글, 우리지역 평가, 회원 유형

**2단계**: 사진 업로드, 인증 농부, 추천, 신고, 신뢰도

**3단계**: 현장 통계, AI와 현장 비교, 지역별 현장지수

**4단계**: Vision AI, 현장 데이터 분석, AI 보조 Feature 연구

## 17. 최종 목표

MK-MAP은 단순한 가격 예측 사이트가 아니다.

공공데이터 + AI + 지도 + 현장 사진 + 지역 커뮤니티 + 인증 농부 + 현장 제보 + 예측 이력을 결합한 **대한민국 농업 정보 플랫폼** 으로 발전한다.

AI는 서비스의 엔진이다. 하지만 플랫폼의 가치는 사용자가 만든 데이터에서 나온다. 장기적으로는 AI보다 커뮤니티와 데이터 자산이 가장 큰 경쟁력이 된다.

현재는 농업 분야에만 집중하며, 농업 플랫폼을 충분히 성공시킨 이후 축산과 수산으로 확장하는 것을 목표로 한다.

## 18. 반드시 지켜야 할 원칙

1. 기능을 많이 만드는 것이 목표가 아니다.
2. AI 정확도보다 사용자가 매일 방문할 이유를 만드는 것이 중요하다.
3. 사용자 댓글은 AI 모델을 변경하지 않는다.
4. 사용자 데이터는 현장 참고자료이며, AI와 명확히 구분한다.
5. 커뮤니티는 자유게시판이 아니라 "지역 × 품목" 기반으로 운영한다.
6. 처음부터 모든 작물을 지원하지 않는다.
7. AI는 데이터가 충분한 작물만 제공한다.
8. 데이터가 부족한 작물은 통계 + 커뮤니티 + 현장 제보를 먼저 제공한다.
9. 모든 기능은 "농민이 실제로 도움이 되는가?"를 기준으로 판단한다.
10. MK-MAP의 최종 경쟁력은 AI가 아니라, 시간이 지날수록 축적되는 지역별 농업 데이터와 커뮤니티 네트워크이다.
