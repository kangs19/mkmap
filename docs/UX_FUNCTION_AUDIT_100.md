# MK Map 기능 100조각 점검표

목적: 기능을 크게 뭉뚱그려 보지 않고, 사용자 입장에서 한 조각씩 확인한다. 각 항목은 `정상`, `개선`, `대기` 중 하나로 관리한다. 화면 문구는 기능 설명보다 “현재 무엇을 판단해야 하는가”를 우선한다.

최신 점검일: 2026-07-06

## 점검 원칙

- 어르신 사용자를 기준으로 글씨, 대비, 터치 영역, 판단 문장을 본다.
- 임의 숫자는 표시하지 않는다. 실측, 모델, 보간, 미연동 상태를 내부적으로 구분한다.
- “이 기능은 무엇입니다”라는 설명보다 “현재는 이렇게 보는 게 좋습니다”라는 판단을 보여준다.
- 지도, 팝업, 오른쪽 패널의 가격과 위험 판단은 같은 데이터에서 나와야 한다.
- 공개 API에는 `Column_17` 같은 내부 학습 컬럼명이 절대 노출되지 않아야 한다.

## 다음 우선순위

1. 하위 지도 레벨 hover 팝업을 실제 좌표 테스트로 재현하고 고친다.
2. 팜맵 농지분류 범례와 작물 영역 겹침 표현을 빗금/패턴으로 분리한다.
3. 장기 예측 6개월/1년은 정확도 리포트가 나오기 전 기본 노출을 낮춘다.
4. 재배·시장 탭은 월별 출하량, 지역 출하 순위, 전국 비중 중심으로 재구성한다.
5. 매일 수집/학습/검증/교체 파이프라인의 성공 조건과 롤백 조건을 문서화한다.
