# 05. 데이터 품질 보고서 & 리스크·해결방안

## 5.1 소스별 품질 문제 & 해결
### KAMIS 가격
- 문제: 자릿수/단위 이상치(마늘 155만원=전날10배), 품목단위 혼동(마늘 10/20kg), 결측일(주말·미거래)
- 해결: 중앙값 4배 이상치 가드(_reject_price_outliers) ✅, 단위 메타 중앙화(ITEM_CODE_MAP/catalog) ✅, 결측은 forward-fill/영업일 기준

### MAFRA 실시간 경락(654)
- 문제: **품종 혼입**(배추에 얼갈이/기타), 시장별 표본편차, 산지명 표기흔들림, 이상 낙찰가
- 해결: 표준품종 필터(_is_std_variety) ✅, 시장내/시장간 이상치 트림 ✅, 산지 시도 파싱 ✅, 표본<3 제외 ✅

### 저수율(669)
- 문제: **저수지코드(AREA_SPR_CD) 시군구 매핑 불가**, 시계열 미정렬(월 뒤섞임), 페이지상한 1000
- 해결: 전체 페이징 후 최신월 집계 ✅(전국지표), 지역 매핑은 저수지-시군 코드표 확보 후

### 특보보험(671)
- 문제: 최신성 지연(반기), 월별
- 해결: 재해보험 가입현황(연단위 안정)·과거 특보통계로 활용, 실시간성 낮음 감안

### KMA 기상
- 문제: **과거 관측 미확보**(예보만), 시간대(UTC vs KST) 버그로 갱신정체 발생
- 해결: KST 통일 수정 ✅, 과거 관측은 ASOS/AWS 별도 백필 필요 ⬜

### KOSIS 생산
- 문제: **제공키 무효**, 연별(시군구 분해 제한), 당해 부분수집을 연간값 오인
- 해결: 키 재발급 필요, 미완결연도 제외 로직 ✅

### FarmMap 병해충/토양
- 문제: **키 401(미인증)**, 좌표기반이라 필지→지역 집계 필요
- 해결: data.go.kr 서비스 등록·키형식(Encoding/Decoding) 확인, 필지 좌표→시군구 집계 설계

## 5.2 공통 결측/중복/이상치 관점
- 결측: 가격 주말·미거래일(품목별), 기상 과거관측 전무, 생산 시군구
- 중복: upsert 유니크제약으로 방지(daily_prices item×date×source 등) ✅
- 이상치: 가격 스파이크·품종혼입 → 가드 구축 ✅
- 날짜누락: 겹침수집(days_back)로 자동보충 ✅
- 지역/품목누락: 코드 매핑 마스터로 해소(미구축) ⬜
