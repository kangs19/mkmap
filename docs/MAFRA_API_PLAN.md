## 신규 기획 아이디어 (MK-MAP 2.0 결합)

### A. 가뭄·저수율 리스크 (669) ★최우선
- 지역×품목 페이지에 **주산지 농업용수 저수율** 표시
- 저수율 급락 시 "가뭄 주의 → 공급 감소 우려" 신호 (현장 신호와 별개, 공식 데이터)
- **AI 예측 피처 추가**: 주산지 저수율을 가격예측 입력으로 → 정확도 향상

### B. 재해 리스크 맵 (671) ★
- 지역별 기상특보 누적(태풍/폭염/호우) 히트맵
- 재해보험 가입률 → "이 지역 배추 농가 보험가입 낮음" 등 취약도
- 특보 발생 → 해당 주산지 품목 공급 리스크 알림

### C. 수급 지표 (658) ★
- 도매시장 반입 총물량 추이 → 물량 급감/급증 감지
- **AI 예측 피처**: 물량 지표 추가 (물량↓ → 가격↑ 선행지표)

### D. 유통 마진 인사이트 (217+163)
- 도매가 vs 소매가 격차 → "산지 폭락인데 소매는 그대로" 같은 소비자 체감 콘텐츠

### E. 친환경 프리미엄 (160)
- 친환경 vs 일반 가격차 → 친환경 전환 농가 의사결정 지원
